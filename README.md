# vuecrud

## What it is
Library of crud UI components to automatically create crud UIs based on JsonSchema made for OpenApp.

## Demo app - how to use
In the demo app, only refer to the library code by importing 'index.js'. This closely mimics use of the library in actual consumer projects. As index.js is the public API of the library.

## Nodejs version
Build using Node v16.15.1
Use NVM for nodejs version management.
https://www.getfishtank.com/blog/use-nvm-to-install-multiple-node-versions
Make sure that you have NOT yet installed node.js, so "program files/nodejs" should not exist.
Install nvm-setup.exe https://github.com/coreybutler/nvm-windows/releases

```
nvm install v16.15.1
nvm use v16.15.1 
```
